# 🎄 Joulukalenteri 2023

Interaktiivinen joulukalenteri selaimessa. Luukun voi avata vain kuluvana tai aiempana päivänä (päivämäärätarkistus `Date`-oliolla), ja avattu luukku näyttää kuvan, videon tai tekstin.

**Tekniikat:** JavaScript, jQuery, HTML, CSS  
**Opittua:** DOM-käsittely, tapahtumankäsittelijät, dynaaminen sisältö  
**Huom:** Varhainen harjoitustyö opintojen alusta (2023). Koodin kommentoinnissa on käytetty tekoälyä apuna, ulkoasu ja rakenne ovat omaa suunnittelua.
